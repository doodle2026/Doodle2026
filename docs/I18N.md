## Mails + .ics (phase 4)
- `events.locale`, `participants.locale`, `invitations.locale` (VARCHAR(5), NOT NULL; migration default 'da' dropped immediately).
- Poll/participant locale: `locale` in the request body (our pages send the active one) → `NEXT_LOCALE` cookie → Accept-Language → en.
- Invitation locale: `locale` in the invite request, else the poll's. Mail language = invitation → poll → en.
- Templates: Doodle UI `email/<kind>.<lang>.{html,txt}` + `strings.<lang>.json` (subject, preheader, From, .ics), synced with `node scripts/sync-email-templates.mjs`. Footer text from `messages/<lang>.json` `email.footerText`.
- Mail links are always `APP_URL/<locale>/…` (APP_URL stays without locale). `List-Unsubscribe` stays `/api/u/p/<t>` (API, no locale).
- `.ics`: `?locale=` (the result banner passes the active one) → cookie/Accept-Language → poll; SUMMARY/DESCRIPTION/URL and PRODID language follow it.
